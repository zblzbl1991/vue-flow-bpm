## ADDED Requirements

### Requirement: BPMN 元素拖拽创建

编辑器 SHALL 提供 BPMN 元素面板，用户可以通过拖拽方式将元素添加到画布。

#### Scenario: 拖拽添加用户任务
- **WHEN** 用户从元素面板拖拽「用户任务」到画布
- **THEN** 在释放位置创建一个用户任务节点
- **AND** 节点具有默认标签和唯一的 ID

#### Scenario: 拖拽添加网关
- **WHEN** 用户从元素面板拖拽「排他网关」或「并行网关」到画布
- **THEN** 在释放位置创建对应的网关节点
- **AND** 网关以菱形图标显示

### Requirement: 节点连接编辑

编辑器 SHALL 支持通过拖拽连接点在节点之间创建序列流。

#### Scenario: 创建序列流连接
- **WHEN** 用户从一个节点的输出连接点拖拽到另一个节点的输入连接点
- **THEN** 在两个节点之间创建一条序列流连接线
- **AND** 连接线使用箭头指示方向

#### Scenario: 删除序列流连接
- **WHEN** 用户选中一条序列流并按删除键
- **THEN** 该序列流从画布中移除

### Requirement: 节点属性编辑

编辑器 SHALL 允许用户编辑节点的标签和 BPMN 特定属性。

#### Scenario: 编辑节点标签
- **WHEN** 用户双击一个节点或点击编辑按钮
- **THEN** 显示属性编辑面板
- **AND** 用户可以修改节点标签

#### Scenario: 编辑用户任务属性
- **WHEN** 用户选中一个用户任务节点
- **THEN** 属性面板显示「处理人」配置项
- **AND** 用户可以设置任务的执行人

#### Scenario: 编辑网关条件
- **WHEN** 用户选中一条从网关出发的序列流
- **THEN** 属性面板显示「条件表达式」配置项
- **AND** 用户可以设置流转条件

### Requirement: 画布操作

编辑器 SHALL 支持画布的缩放、平移等基本操作。

#### Scenario: 缩放画布
- **WHEN** 用户使用鼠标滚轮
- **THEN** 画布以鼠标位置为中心进行缩放
- **AND** 缩放范围限制在 25% 到 200% 之间

#### Scenario: 平移画布
- **WHEN** 用户按住鼠标左键拖动画布空白区域
- **THEN** 画布随拖拽方向移动

### Requirement: 工作流保存与加载

编辑器 SHALL 支持将当前工作流保存为 JSON 格式，并能从 JSON 加载工作流。

#### Scenario: 保存工作流
- **WHEN** 用户点击保存按钮
- **THEN** 当前工作流的节点和连接数据被导出为 JSON 格式
- **AND** JSON 文件被下载到本地

#### Scenario: 加载工作流
- **WHEN** 用户上传一个有效的工作流 JSON 文件
- **THEN** 画布被清空并加载文件中的节点和连接
- **AND** 所有节点位置和连接关系被正确恢复

### Requirement: 编辑器状态管理

编辑器 SHALL 维护工作流的完整状态，包括节点、连接和选中状态。

#### Scenario: 选中节点
- **WHEN** 用户点击一个节点
- **THEN** 该节点被高亮显示
- **AND** 属性面板显示该节点的属性

#### Scenario: 选中多条序列流
- **WHEN** 用户按住 Shift 点击多条序列流
- **THEN** 所有被点击的序列流都被选中
- **AND** 用户可以批量删除这些序列流

### Requirement: 节点验证规则

编辑器 SHALL 在创建和编辑时执行基本的 BPMN 结构验证。

#### Scenario: 防止非法连接
- **WHEN** 用户尝试将一个节点连接到自己
- **THEN** 连接操作被阻止
- **AND** 显示错误提示

#### Scenario: 检测孤立节点
- **WHEN** 画布中存在没有连接的中间节点（非开始/结束事件）
- **THEN** 在导出时显示警告
- **AND** 列出所有孤立节点

#### Scenario: 确保开始和结束事件
- **WHEN** 工作流缺少开始事件或结束事件
- **THEN** 在导出时显示错误
- **AND** 阻止导出操作

### Requirement: 自定义节点样式

编辑器 SHALL 为不同类型的 BPMN 元素提供符合 BPMN 规范的视觉样式。

#### Scenario: 开始事件样式
- **WHEN** 渲染开始事件节点
- **THEN** 显示为圆形图标
- **AND** 使用绿色填充和粗边框

#### Scenario: 结束事件样式
- **WHEN** 渲染结束事件节点
- **THEN** 显示为圆形图标（比开始事件粗）
- **AND** 使用红色填充和粗边框

#### Scenario: 用户任务样式
- **WHEN** 渲染用户任务节点
- **THEN** 显示为圆角矩形
- **AND** 包含用户图标和标签

#### Scenario: 网关样式
- **WHEN** 渲染网关节点
- **THEN** 显示为菱形图标
- **AND** 排他网关显示「X」标记，并行网关显示「+」标记
