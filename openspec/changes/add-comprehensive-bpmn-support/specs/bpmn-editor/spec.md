# bpmn-editor Specification (Delta)

这是对现有 bpmn-editor 规格的增量更新，添加了增强的属性面板功能。

## ADDED Requirements

### Requirement: 属性面板分组和标签页

属性面板 SHALL 使用标签页和分组结构来组织不同类型的属性配置。

#### Scenario: 属性标签页切换
- **WHEN** 用户选中节点后点击属性面板的标签页
- **THEN** 显示对应标签页的属性配置
- **AND** 标签页包括：Basic（基础）、Execution（执行）、Form（表单）、IO（输入输出）、Advanced（高级）

#### Scenario: 属性分组折叠/展开
- **WHEN** 用户点击属性分组的折叠/展开按钮
- **THEN** 分组内容被折叠或展开
- **AND** 折叠状态在会话中保持

### Requirement: 异步配置属性

编辑器 SHALL 支持配置节点和任务的异步执行属性，以支持 Flowable 的异步执行功能。

#### Scenario: 配置异步执行
- **WHEN** 用户在属性面板的「高级」标签页中配置异步属性
- **THEN** 可以选择「异步前」（asyncBefore）、「异步后」（asyncAfter）或「异步」（async）
- **AND** 配置的异步属性被正确导出到 BPMN XML

#### Scenario: 异步属性验证
- **WHEN** 用户同时启用「异步前」和「异步后」
- **THEN** 系统自动设置「异步」标志
- **AND** 在属性面板中显示提示信息

### Requirement: 跳过表达式配置

编辑器 SHALL 支持配置任务的跳过表达式，允许在运行时跳过任务执行。

#### Scenario: 配置跳过表达式
- **WHEN** 用户在任务属性面板中配置跳过表达式
- **THEN** 可以输入布尔表达式（如 `${skipThisTask}`）
- **AND** 表达式在运行时被评估，如果为 true 则跳过任务

#### Scenario: 跳过表达式验证
- **WHEN** 用户输入跳过表达式
- **THEN** 系统验证表达式语法
- **AND** 如果语法错误，显示错误提示和建议

### Requirement: 优先级和到期日期配置

编辑器 SHALL 支持配置用户任务的优先级和到期日期属性。

#### Scenario: 配置任务优先级
- **WHEN** 用户在任务属性面板中配置优先级
- **THEN** 可以输入数字优先级（如 50）
- **AND** 优先级影响任务在用户任务列表中的排序

#### Scenario: 配置到期日期
- **WHEN** 用户在任务属性面板中配置到期日期
- **THEN** 可以输入日期表达式（如 `${dueDate}`）
- **AND** 支持相对日期表达式（如 `${now + 7 days}`）

### Requirement: 脚本任务属性配置

编辑器 SHALL 支持配置脚本任务的脚本格式和脚本内容。

#### Scenario: 配置脚本格式
- **WHEN** 用户选中脚本任务节点
- **THEN** 属性面板显示「脚本格式」配置项
- **AND** 可以选择脚本语言（如 JavaScript、Groovy、Python）

#### Scenario: 编辑脚本内容
- **WHEN** 用户在属性面板中编辑脚本内容
- **THEN** 提供多行文本编辑器
- **AND** 支持基本的语法高亮（可选）
- **AND** 脚本内容被正确导出到 BPMN XML

### Requirement: 业务规则任务属性配置

编辑器 SHALL 支持配置业务规则任务的规则引用、输入变量和结果变量。

#### Scenario: 配置规则引用
- **WHEN** 用户选中业务规则任务节点
- **THEN** 属性面板显示「规则引用」配置项
- **AND** 可以输入规则定义的标识符

#### Scenario: 配置规则变量
- **WHEN** 用户配置业务规则任务
- **THEN** 可以设置规则变量输入和结果变量
- **AND** 变量映射被正确导出到 BPMN XML

### Requirement: 调用活动属性配置

编辑器 SHALL 支持配置调用活动的被调用流程和变量继承属性。

#### Scenario: 配置被调用流程
- **WHEN** 用户选中调用活动节点
- **THEN** 属性面板显示「被调用元素」配置项
- **AND** 可以输入或选择要调用的流程 ID

#### Scenario: 配置变量继承
- **WHEN** 用户配置调用活动
- **THEN** 可以选择是否继承父流程的变量
- **AND** 可以配置变量传递规则（本地、父流程、继承）

### Requirement: 事件属性配置增强

编辑器 SHALL 支持配置各种事件类型的扩展属性，包括定时器、消息、信号和错误。

#### Scenario: 配置定时器事件
- **WHEN** 用户选中定时器事件节点
- **THEN** 属性面板显示定时器配置选项
- **AND** 可以选择定时器类型（duration、date、cycle）
- **AND** 根据类型显示不同的配置字段：
  - duration: 持续时间表达式（如 `PT5M`）
  - date: 日期时间表达式（如 `${dueDate}`）
  - cycle: 循环表达式（如 `R5/PT10M`）

#### Scenario: 配置消息/信号事件
- **WHEN** 用户选中消息或信号事件节点
- **THEN** 属性面板显示「消息引用」或「信号引用」配置项
- **AND** 可以输入或选择消息/信号的标识符

#### Scenario: 配置错误事件
- **WHEN** 用户选中错误事件节点
- **THEN** 属性面板显示「错误代码」配置项
- **AND** 可以输入或选择错误代码
- **AND** 支持配置错误变量

### Requirement: 序列流条件类型配置

编辑器 SHALL 支持配置序列流条件的类型（表达式或脚本）。

#### Scenario: 配置表达式条件
- **WHEN** 用户选中序列流并配置条件
- **THEN** 默认使用表达式类型
- **AND** 可以输入 UEL 表达式（如 `${approved == true}`）

#### Scenario: 配置脚本条件
- **WHEN** 用户选择条件类型为「脚本」
- **THEN** 可以选择脚本格式
- **AND** 可以输入脚本内容
- **AND** 脚本返回布尔值决定是否执行序列流

### Requirement: 属性验证和错误提示

编辑器 SHALL 在属性配置时提供实时验证和错误提示。

#### Scenario: ID 格式验证
- **WHEN** 用户输入 BPMN ID
- **THEN** 系统验证 ID 格式（字母或下划线开头，只包含字母、数字、下划线、连字符）
- **AND** 如果格式错误，显示错误提示

#### Scenario: 必填字段验证
- **WHEN** 用户尝试保存属性配置
- **THEN** 系统验证所有必填字段
- **AND** 如果有必填字段为空，显示错误提示并高亮字段

#### Scenario: 表达式语法验证
- **WHEN** 用户输入表达式
- **THEN** 系统验证表达式语法
- **AND** 如果语法错误，显示错误提示和建议修复

### Requirement: 属性预设和模板

编辑器 SHALL 支持属性配置的预设和模板功能，提高配置效率。

#### Scenario: 应用属性预设
- **WHEN** 用户在属性面板中选择预设模板
- **THEN** 预设的属性值被自动填充到表单
- **AND** 用户可以根据需要修改预设值

#### Scenario: 保存自定义预设
- **WHEN** 用户配置了常用属性组合后点击「保存为预设」
- **THEN** 系统保存当前配置为自定义预设
- **AND** 预设可以在后续创建同类节点时应用

### Requirement: 工具提示和帮助文档

编辑器 SHALL 在属性面板中提供工具提示和帮助文档链接。

#### Scenario: 显示属性工具提示
- **WHEN** 用户鼠标悬停在属性字段标签上
- **THEN** 显示该属性的简短说明
- **AND** 工具提示包含属性用途和示例值

#### Scenario: 链接到帮助文档
- **WHEN** 用户点击属性面板中的「帮助」按钮
- **THEN** 打开相关属性配置的帮助文档
- **AND** 文档包含详细的说明和示例

## MODIFIED Requirements

### Requirement: 节点属性编辑

编辑器 SHALL 允许用户编辑节点的标签和 BPMN 特定属性。

#### Scenario: 编辑用户任务属性
- **WHEN** 用户选中一个用户任务节点
- **THEN** 属性面板显示以下配置项：
  - **基础属性**：ID、名称、文档说明
  - **执行属性**：处理人、候选用户、候选组
  - **高级属性**：优先级、到期日期、跳过表达式
  - **执行监听器**：监听器列表和配置
  - **表单属性**：表单字段配置
  - **多实例**：串行/并行、集合变量、完成条件

#### Scenario: 编辑服务任务属性
- **WHEN** 用户选中一个服务任务节点
- **THEN** 属性面板显示以下配置项：
  - **基础属性**：ID、名称、文档说明
  - **执行属性**：表达式、委托表达式、Java 类
  - **输入/输出参数**：参数列表和配置
  - **高级属性**：跳过表达式、异步配置
  - **执行监听器**：监听器列表和配置
  - **多实例**：串行/并行、集合变量、完成条件

#### Scenario: 编辑网关条件
- **WHEN** 用户选中一条从网关出发的序列流
- **THEN** 属性面板显示以下配置项：
  - **基础属性**：名称、文档说明
  - **条件配置**：条件类型（表达式/脚本）、条件内容
  - **默认流转**：设置该序列流为网关的默认流转（仅排他网关）

### Requirement: 编辑器状态管理

编辑器 SHALL 维护工作流的完整状态，包括节点、连接和选中状态。

#### Scenario: 选中节点并显示属性
- **WHEN** 用户点击一个节点
- **THEN** 该节点被高亮显示
- **AND** 属性面板显示该节点的属性
- **AND** 属性面板根据节点类型显示对应的属性组

#### Scenario: 选中序列流并显示条件
- **WHEN** 用户点击一条序列流
- **THEN** 序列流被高亮显示
- **AND** 属性面板显示序列流的条件配置
- **AND** 如果序列流从网关出发，显示条件表达式编辑器
